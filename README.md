Institutional-grade modern C++17 SDK for connecting to the **[XYO.Financial](https://xyo.financial)** AI banking transaction enrichment API. Transform raw, cryptic bank narrative strings (e.g. `TST* COSTA 4928 LONDON GB`) into structured merchant intelligence, clean taxonomy categories, logos, and verified geolocation data.

---

## Key Features

- **Modern C++17 Design**: Clean, idiomatic C++ with `std::optional`, `std::vector`, and move semantics.
- **PIMPL Encapsulation**: Clean public headers (`xyo/client.hpp`) with zero leakage of third-party HTTP/JSON internals.
- **Synchronous & Asynchronous Operations**: Real-time single transaction enrichment and high-throughput bulk batch processing with asynchronous status polling.
- **Structured Error Hierarchy**: Tagged error categories (`validation`, `transport`, `http`, `parsing`) with HTTP status codes and transport error diagnostics.
- **Thread-Safe**: `xyo::Client` instances are thread-safe and can be safely shared across concurrent execution threads.
- **Enterprise Build System**: Full support for CMake (`find_package`, `FetchContent`, `add_subdirectory`), Conan 2, and vcpkg.

## Quickstart

```cpp
#include <xyo/client.hpp>
#include <iostream>

int main() {
  try {
    // 1. Initialize client configuration
    xyo::ClientConfig config("YOUR_XYO_API_KEY");
    config.request_timeout_ms = 10000; // 10s request timeout

    xyo::Client client(std::move(config));

    // 2. Enrich a single transaction
    xyo::EnrichmentRequest request{
        /* content      = */ "COSTA PICKUP LONDON",
        /* country_code = */ "GB"
    };

    xyo::EnrichmentResponse response = client.enrichTransaction(request);

    std::cout << "Merchant:    " << response.merchant << "\n";
    std::cout << "Description: " << response.description << "\n";
    std::cout << "Categories:  ";
    for (const auto& cat : response.categories) {
      std::cout << "[" << cat << "] ";
    }
    std::cout << "\n";

    if (response.location) {
      std::cout << "Location:    " << *response.location << "\n";
    }
    if (response.address) {
      std::cout << "Address:     " << *response.address << "\n";
    }

  } catch (const xyo::Error& e) {
    std::cerr << "XYO Error: " << e.what() << " (HTTP " << e.http_status_code() << ")\n";
    return 1;
  }
  return 0;
}
```

## Comprehensive Examples

### 1. Single Transaction Enrichment (`enrichTransaction`)

Synchronously enrich an individual transaction narrative into standardized merchant metadata:

```cpp
#include <xyo/client.hpp>
#include <iostream>

void enrichSingle(const xyo::Client& client) {
  xyo::EnrichmentRequest req{
      "STRBUKS GREENWICH SE10", // Raw bank string (max 128 chars)
      "GB"                      // ISO 3166-1 alpha-2 country code
  };

  xyo::EnrichmentResponse res = client.enrichTransaction(req);

  std::cout << "Merchant:    " << res.merchant << "\n";
  std::cout << "Description: " << res.description << "\n";
  std::cout << "Logo (B64):  " << res.logo.substr(0, 30) << "...\n";

  // Optional fields
  if (res.location.has_value()) {
    std::cout << "Location:    " << res.location.value() << "\n";
  }
  if (res.address.has_value()) {
    std::cout << "Address:     " << res.address.value() << "\n";
  }
}
```

### 2. Bulk Transaction Enrichment (`enrichTransactions`)

Submit high-volume transaction batches asynchronously for background processing:

```cpp
#include <xyo/client.hpp>
#include <iostream>
#include <vector>

xyo::BulkEnrichmentResponse enrichBatch(const xyo::Client& client) {
  std::vector<xyo::EnrichmentRequest> batch = {
      {"UBER *TRIP HELP.UBER.COM", "US"},
      {"NETFLIX.COM PAYMENT", "GB"},
      {"AMZN MKTP US*2819873", "US"},
      {"TESCO STORES 2891", "GB"}
  };

  // Submit batch job (returns job identifier and download URL)
  xyo::BulkEnrichmentResponse bulk = client.enrichTransactions(batch);

  std::cout << "Job ID:       " << bulk.id << "\n";
  std::cout << "Results Link: " << bulk.link << "\n";

  return bulk;
}
```

### 3. Job Status Polling (`getEnrichmentStatus`)

Poll the status of an asynchronous bulk enrichment job:

```cpp
#include <xyo/client.hpp>
#include <chrono>
#include <iostream>
#include <thread>

void pollJobStatus(const xyo::Client& client, const std::string& jobId) {
  while (true) {
    xyo::EnrichmentStatus status = client.getEnrichmentStatus(jobId);
    std::cout << "Current Job Status: " << xyo::to_string(status) << "\n";

    if (status == xyo::EnrichmentStatus::ready) {
      std::cout << "Batch enrichment complete! Download archive from results link.\n";
      break;
    } else if (status == xyo::EnrichmentStatus::failed) {
      std::cerr << "Batch enrichment job failed processing.\n";
      break;
    }

    // Still pending, wait before polling again
    std::this_thread::sleep_for(std::chrono::seconds(2));
  }
}
```

### 4. Downloading Bulk Results Archive (`downloadEnrichmentCollection`)

Once a bulk enrichment job is `ready`, fetch and unpack the resulting compressed archive using `downloadEnrichmentCollection`. The SDK performs an HTTP GET request with Bearer authentication and `Accept: application/gzip`, decompresses the `.tar.gz` stream, and decodes each JSON tar entry into domain `xyo::EnrichmentResponse` models:

```cpp
#include <xyo/client.hpp>
#include <iostream>
#include <vector>

void downloadResults(const xyo::Client& client, const std::string& downloadUrl) {
  // downloadUrl is the `link` URL returned from BulkEnrichmentResponse
  std::vector<xyo::EnrichmentResponse> records =
      client.downloadEnrichmentCollection(downloadUrl);

  std::cout << "Downloaded " << records.size() << " enriched transactions:\n";

  for (const auto& record : records) {
    std::cout << "----------------------------------------\n";
    std::cout << "Merchant:    " << record.merchant << "\n";
    std::cout << "Description: " << record.description << "\n";
    std::cout << "Categories:  ";
    for (const auto& cat : record.categories) {
      std::cout << "[" << cat << "] ";
    }
    std::cout << "\n";

    if (record.location) {
      std::cout << "Location:    " << *record.location << "\n";
    }
    if (record.address) {
      std::cout << "Address:     " << *record.address << "\n";
    }
  }
}
```

### 5. Structured Error Handling (`xyo::Error`)

The SDK throws `xyo::Error` (derived from `std::runtime_error`) on validation failures, transport failures, HTTP errors, or response parsing errors:

```cpp
#include <xyo/client.hpp>
#include <iostream>

void handleErrorsSafely(const xyo::Client& client) {
  try {
    xyo::EnrichmentRequest req{"", "GB"}; // Empty content will trigger validation error
    auto res = client.enrichTransaction(req);
  } catch (const xyo::Error& err) {
    std::cerr << "[SDK Error] " << err.what() << "\n";

    switch (err.category()) {
      case xyo::ErrorCategory::validation:
        std::cerr << "Category: Client-side validation failure (e.g. empty API key or content).\n";
        break;

      case xyo::ErrorCategory::transport:
        std::cerr << "Category: Network transport failure (e.g. DNS timeout, connection reset).\n";
        std::cerr << "Transport code: " << err.transport_code() << "\n";
        break;

      case xyo::ErrorCategory::http:
        std::cerr << "Category: HTTP error response from server.\n";
        std::cerr << "HTTP Status Code: " << err.http_status_code() << "\n";
        if (err.http_status_code() == 401) {
          std::cerr << "Authentication error: Check your API key.\n";
        } else if (err.http_status_code() == 429) {
          std::cerr << "Rate limit exceeded. Implement backoff retry.\n";
        }
        break;

      case xyo::ErrorCategory::parsing:
        std::cerr << "Category: Payload serialization / deserialization error.\n";
        break;
    }
  } catch (const std::exception& err) {
    std::cerr << "[Standard Exception] " << err.what() << "\n";
  }
}
```

## Integration & Installation

### Option A: CMake `find_package` (Installed / Conan / vcpkg)

Once installed system-wide or via a package manager, link the imported `XYO::SDK` target:

```cmake
cmake_minimum_required(VERSION 3.16)
project(FinancialApp LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# Find XYO SDK package
find_package(XYOSDK CONFIG REQUIRED)

add_executable(financial_app main.cpp)
target_link_libraries(financial_app PRIVATE XYO::SDK)
```

### Option B: CMake `FetchContent`

Integrate directly from source without pre-installed binaries:

```cmake
include(FetchContent)

FetchContent_Declare(
  xyo_sdk
  GIT_REPOSITORY https://github.com/xyo-financial/sdk-cpp.git
  GIT_TAG        v2.0.0
)
FetchContent_MakeAvailable(xyo_sdk)

add_executable(financial_app main.cpp)
target_link_libraries(financial_app PRIVATE XYO::SDK)
```

### Option C: CMake `add_subdirectory`

If the SDK is cloned as a Git submodule or vendored in your project tree:

```cmake
add_subdirectory(vendor/sdk-cpp)

add_executable(financial_app main.cpp)
target_link_libraries(financial_app PRIVATE XYO::SDK)
```

### Option D: Conan 2

Add the SDK requirement to your `conanfile.txt`:

```ini
[requires]
xyo-sdk-cpp/2.0.0

[generators]
CMakeDeps
CMakeToolchain

[layout]
cmake_layout
```

Export and consume locally:

```sh
# Export SDK recipe to local cache
conan export .

# In your consuming project:
conan install . --build=missing
cmake --preset conan-release
cmake --build --preset conan-release
```

### Option E: vcpkg

Install via vcpkg manifest or CLI:

```sh
vcpkg install xyo-sdk-cpp
```

```cmake
# Pass toolchain to CMake
cmake -B build -S . -DCMAKE_TOOLCHAIN_FILE=${VCPKG_ROOT}/scripts/buildsystems/vcpkg.cmake
```

## Configuration Reference

The `xyo::ClientConfig` struct provides complete control over client behavior:

| Field | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `api_key` | `std::string` | *(Required)* | Bearer API token from the XYO dashboard |
| `base_url` | `std::string` | `https://api.xyo.financial` | API gateway endpoint URL |
| `connect_timeout_ms` | `long` | `5000` (5s) | HTTP socket connection timeout in milliseconds |
| `request_timeout_ms` | `long` | `30000` (30s) | HTTP overall request timeout in milliseconds |
| `max_collection_size` | `std::size_t` | `1000` | Maximum items per batch collection request |
